Joint (Concept + Code) Learning Material for supervised fine-tuning (SFT) of LLMs.
This repo is a learning journal for SFT. 
The goal is to arrange the basic code in a simple pedagogical manner.


The associated concepts are described in comments which are written in a 

(i) Jargon-free, cause-effect style, 
(ii) clarifies the motivation (what are we trying to achieve with this concept?), 
(iii) provides context on inner workings (behind the scenes nuances on that are not immediately apparent),
(iv) describes how the concept will be used later in the repo.
